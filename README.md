## ✨ Key Features

- ✅ **Responsive Design**: Automatically adjusts layout for web, tablet, and mobile
- 🧠 **State Management**: Efficient state handling using `Provider`
- 📊 **Data Visualization**: Clean and customizable charts with `fl_chart`
- 🎨 **Custom Styling**: Google Fonts + SVG icons for scalable UI
- 📱 **Multi-platform Support**: Works across Android, iOS, and Web
- 📦 **Modular Architecture**: Scalable and maintainable code structure
- 🧪 **Testing Ready**: Includes unit test setup using `flutter_test`
- 🧰 **Custom Icons**: Launcher icons for all platforms via `flutter_launcher_icons`

---

## 📱 Responsive Layout

| Platform | Layout Behavior |
|----------|------------------|
| Web      | Sidebar + Expanded content area |
| Tablet   | Collapsible drawer with adaptive grid |
| Mobile   | Bottom navigation + stacked UI sections |

Responsiveness is achieved using `LayoutBuilder`, `MediaQuery`, and custom responsive widgets.
